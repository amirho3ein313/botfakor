# سورس ربات خوش‌آمدگویی بله

طراحی و کدنویسی: سروش مقدمی — فیلتور (filtori.com)

## راه‌اندازی
1. از BotFather در بله توکن ربات را بگیر.
2. پایتون ۳ را نصب کن و pip install requests را اجرا کن.
3. در فایل bot.py مقدار TOKEN را جایگزین کن.
4. python bot.py را اجرا کن و در بله /start بزن.

## نصب وابستگی
```
pip install -r requirements.txt
```

## اجرا
```
python bot.py
```
